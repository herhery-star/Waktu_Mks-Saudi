WAKTU MAKASSAR — PWA
Isi paket:
- index.html: aplikasi jam analog/digital dan kalkulator cut-off
- manifest.webmanifest: metadata instalasi PWA
- sw.js: service worker untuk cache/offline dasar
- icons/: ikon aplikasi berbagai ukuran

CARA MEMASANG / MENJALANKAN
1. Unggah seluruh isi folder ini ke root repositori GitHub Pages (jangan hanya index.html).
2. Aktifkan GitHub Pages pada Settings > Pages jika belum aktif.
3. Buka URL HTTPS GitHub Pages di Chrome Android.
4. Pilih menu browser > Install app / Tambahkan ke layar utama.
5. Jika perubahan tidak terlihat setelah update, tutup aplikasi dan muat ulang; versi cache dapat perlu dibersihkan.

CATATAN
- Jam menggunakan zona waktu IANA Asia/Makassar dan Asia/Riyadh secara otomatis.
- Kalkulator mengurangi 5 jam dari waktu cut-off Makassar. Gunakan hanya jika portal BBM memang memakai WITA.
- Ikon PNG di folder icons dihasilkan dari konsep visual aplikasi.
